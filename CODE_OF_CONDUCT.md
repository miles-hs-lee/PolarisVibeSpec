# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating in this project — through issues, pull requests, discussions,
or any other channel — you agree to abide by its terms.

## Reporting

If you observe behavior that violates the Contributor Covenant, please report
it by opening a private GitHub Security Advisory at
<https://github.com/miles-hs-lee/PolarisVibeSpec/security/advisories/new>
or by emailing the maintainer (see commit history for contact).

Reports are reviewed in confidence. The maintainer will acknowledge receipt
within 7 days and follow up with the reporter on next steps.
